# Revision Notes — 2026-08-28 Hotfix

This hotfix was created after visual review of the previously delivered FINAL ZIP.

## Fixed in this revision

1. **Grouped-data tables**
   - Reworked `MathRenderer` so `$$\begin{array}...\end{array}$$` is rendered as an actual HTML table instead of showing raw/red LaTeX.

2. **Integral / trigonometric / piecewise-formula rendering**
   - Reworked mixed-content math tokenization.
   - Added safe handling for `\begin{cases}...\end{cases}`.
   - Reduced aggressive auto-wrapping that previously caused nested math and red rendering.

3. **Synthetic diagrams removed**
   - Disabled placeholder SVG diagrams generated by the app.
   - This avoids misleading AI-style diagrams when the original source figure is not available in the dataset.

## Important limitation kept explicit

- **Original source figures are not yet embedded as image payloads in the imported question-bank data.**
- Therefore this hotfix removes misleading placeholder diagrams but does **not** yet reconstruct every original source figure automatically.
- A future figure-migration pass should map the original source images into structured question assets.
